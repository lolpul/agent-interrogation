# Подготовка стабильного релиза

Цель — проверять целостность скилла и ZIP на Windows и Linux до публикации. Текущая установка из `interrogation/`, логика `SKILL.md` и MIT-лицензия входят в проверку на отсутствие изменений.

| Этап | Изменения | Критерий приёмки |
| --- | --- | --- |
| Автоматические проверки | Workflow, тест разбора YAML, сборка существующим скриптом | Unit-тесты, сверка копий и сборка ZIP проходят на обоих раннерах. Каждый раннер сохраняет свой ZIP. |
| Подготовка проекта | Шаблоны Issues, README, нейтральные сценарии, журнал и критерии релиза | Ссылки ведут к нужным разделам. Результаты ручных сценариев привязаны к проверенной ревизии. |
| Передача на ревью | Отдельная ветка и PR | Проверены результаты GitHub Actions. Публикация релиза требует отдельного подтверждения владельца. |

## Решения

- Использован существующий сборщик. Он проверяет совпадение обеих копий `SKILL.md` и `agents/openai.yaml`, состав ZIP и CRC.
- YAML разбирается отдельными тестами с PyYAML. Установка и сборщик сохраняют прежние зависимости.
- Оба раннера публикуют ZIP как артефакт проверки. Workflow использует токен с правом чтения содержимого репозитория.

## Проверка и откат

- `python -m unittest discover -s tests -v`, `python scripts/build_plugin.py --check` и `python scripts/build_plugin.py` прошли на Windows с Python 3.14.4 и Ubuntu через WSL с Python 3.12.3.
- `actionlint` проверил workflow. Отдельно сверены все шесть файлов ZIP с исходниками, YAML обоих шаблонов Issues и относительные ссылки в документации.
- [Ручные сценарии Codex](../MANUAL_TEST_LOG.md) ожидают запуска. Результаты hosted CI привязаны к PR.
- Для отката после объединения отмените коммит этой правки через отдельный PR.
