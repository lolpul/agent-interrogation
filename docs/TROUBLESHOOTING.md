# Troubleshooting

## Codex не видит `$interrogation`

- Убедитесь, что файл находится по пути `.../skills/interrogation/SKILL.md`, а не внутри повторной вложенной папки.
- Откройте новую сессию Codex после установки.
- Убедитесь, что `SKILL.md` начинается с YAML frontmatter c `name: interrogation` и `description:`.
- Убедитесь, что каталог skills соответствует поддерживаемому расположению в вашей версии Codex. Попробуйте рекомендуемый `~/.agents/skills/`.
- Если есть две копии `interrogation`, удалите дубликат, чтобы избежать неоднозначного разрешения.

## Codex сразу пишет код

- Убедитесь, что вы **явно активировали** `$interrogation`.
- Сначала переключитесь в `/plan`, при необходимости включите `Read Only`.
- Попросите Codex показать `INTERROGATION_LOCKED` и открытые блокирующие вопросы.
- Не считайте `SKILL.md` механизмом гарантированного ограничения записи: это инструкция модели, и её исполнение может быть несовершенным.

## Codex задаёт слишком много вопросов

- Попробуйте `$interrogation mode=light ...`, если задача локальная.
- Укажите ограничения и уже согласованные решения в запросе.
- Попросите задавать по одному вопросу. Необходимо всё равно закрыть существенные блокеры.

## Codex выбирает Deep почти для всего

- Проверьте фактические значения факторов S/U/R/I и объяснения риска.
- Дайте более узкие границы задачи или явно выберите `mode=standard`; это не снимает обязательства закрывать блокирующие вопросы.

## Codex забыл решения между сессиями

- Skill не имеет постоянной базы решений. Перенесите финальное ТЗ или краткую сводку в новый чат.

## Параметр `mode=deep` не распознан

- Это не настоящий CLI-флаг. Пишите его **в тексте запроса после `$interrogation`**, например `$interrogation mode=deep Разработай ТЗ ...`.

## Как сообщить об ошибке

См. [CONTRIBUTING.md](../CONTRIBUTING.md). Укажите версию Codex, путь установки, точный вызов и ожидаемое/фактическое поведение; не публикуйте приватные фрагменты кода и секреты.


## Агент не установил skill по одной ссылке

Одна ссылка не является однозначной командой. Передайте агенту: «Установи Interrogation Mode из https://github.com/lolpul/agent-interrogation. Прочитай AGENT_INSTALL.md и сообщи результат». Проверьте сетевой доступ и разрешения на запись. Для облачных/удалённых агентов локальная установка может быть недоступна или не синхронизироваться.

## Skill установлен, но команда вызова не работает

Префиксы различаются: Codex — `$interrogation`; Claude Code / Cursor — `/interrogation`; OpenCode — `@interrogation`; Gemini CLI — активация skill при явной просьбе. Убедитесь, что skill установлен в каталог именно вашего агента и есть `interrogation/SKILL.md`.
