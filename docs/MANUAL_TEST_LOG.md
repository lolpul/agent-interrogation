## Как записать прогон

Добавьте датированную запись с SHA проверенной ревизии или тега, именем проверяющего, клиентом и его версией, ОС, способом установки и активным режимом Codex. Для каждого выполненного сценария укажите номер, статус «Прошёл» или «Не прошёл», наблюдаемое поведение и при наличии ссылку на обезличенный результат или Issue. Для сценария 9 сохраните вывод `git status --porcelain` до и после. Сохраняйте предыдущие записи при проверке новой ревизии.

Результаты GitHub Actions доступны в [журнале CI](https://github.com/lolpul/agent-interrogation/actions/workflows/ci.yml). Таблица выше предназначена для наблюдений в агенте.
