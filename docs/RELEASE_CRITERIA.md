# Критерии стабильного релиза

## Проверка кандидата

- [ ] PR прошёл ревью. Ветка релиза содержит согласованные изменения, а блокирующие Issues закрыты.
- [ ] Для ревизии, которую планируется публиковать, зелёные обе задачи [GitHub Actions](https://github.com/lolpul/agent-interrogation/actions/workflows/ci.yml). Они выполняют unit-тесты, разбирают YAML frontmatter, проверяют метаданные и совпадение обеих копий скилла, собирают ZIP и проверяют его состав и CRC.
- [ ] Из успешного запуска скачан один ZIP. Имя файла и версии двух манифестов согласованы с планируемым тегом. В архиве есть MIT LICENSE и только файлы из списка упаковки.
- [ ] [Сценарии 1–12](../TEST_SCENARIOS.md) вручную пройдены в Codex на кандидате. Запись в [журнале](MANUAL_TEST_LOG.md) содержит SHA испытанного коммита, версию клиента, ОС и наблюдения. Повторите затронутые проверки, если после прогона изменились скилл, манифесты, упаковка или процедура установки. Проверки других клиентов записывайте отдельными прогонами.
- [ ] В [CHANGELOG.md](../CHANGELOG.md) указаны изменения кандидата. [Установка агентом](../AGENT_INSTALL.md) и [ручная установка](../INSTALL.md) ведут к каноническому каталогу `interrogation/`.

## Публикация

Владелец репозитория отдельно подтверждает релиз после проверки критериев. После подтверждения тег указывает на проверенную ревизию. В GitHub Release приложите проверенный ZIP и заметки об изменениях. GitHub Actions сохраняет ZIP как артефакт CI.
